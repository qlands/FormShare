Memory required:  8GB of RAM

Before you run docker-compose you need to:

1) Install docker-compose and give it enough memory
sudo apt-get install -y docker-compose
sudo sysctl -w vm.max_map_count=262144
echo 'vm.max_map_count=262144' | sudo tee -a /etc/sysctl.d/60-vm-max_map_count.conf

2) Create a .env file using the example
cp .env.example .env

3) Edit .env file to change:
-The mysql security credentials:
line 19: MYSQL_ROOT_PASSWORD=change_me_mysql_root

- The Elasticsearch security credentials:
line 24: ELASTIC_PASSWORD=change_me_elastic

-The admin credentials:
line 27: FORMSHARE_ADMIN_USER: admin
line 28: FORMSHARE_ADMIN_EMAIL: admin@myserver.com
line 29: FORMSHARE_ADMIN_PASSWORD: change_me_admin

4) Start MySQL and Elasticsearch
docker compose --env-file .env -f servers.yml up -d

5) Start FormShare
docker compose --env-file .env -f formshare.yml up -d

Docker will pull the necessary images and run FormShare. After all images are pulled and
all services run, you will be able to access FormShare at http://localhost:5900/formshare.
From there you can poxy pass it using Apache.
